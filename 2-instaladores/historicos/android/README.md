# Android Local

Se retiró la compilación Firebase. La APK de local/ es la versión histórica 3.1.1.
La nueva APK y su recibo de firma/versión se generan con cada push en el artefacto
**Lankdea-Android**, y también se incluyen en **Lankdea-Paquete-Completo**.

Las APK de pruebas no se publican como actualizaciones oficiales. Para distribución
se requiere la firma estable descrita en
[ACTUALIZACIONES.md](../../../1-programa/docs/ACTUALIZACIONES.md).
